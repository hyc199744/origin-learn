关于 Web3Origin

一句话：Web3Origin 是 Origin（起源）生态的链上数据查询与研究平台。我们把"别人说的"变成"你自己上链查到的"——查合约、查钱包、看日报、查证据，全部可在区块浏览器独立核实。

我们是谁

Web3Origin（web3origin.com，又名"起源学习站"）是一个围绕 Origin / LGNS / Anubis Chain 的独立链上数据平台，中文为主、提供英文版（/en/）。我们不代管资产、不连钱包，只做公开链上数据的查询、核实与研究。

解决什么问题

Web3 里最大的问题是信息不对称——普通用户往往只能听"别人说"。Web3Origin 让你自己上链核实：一个代币能不能增发、一个钱包持有什么做过什么、一个事件是否真的发生、国库里到底有多少钱，都能一键查到并核对，不必只信任何人一面之词（DYOR）。

提供哪些数据 / 工具

  • 合约验证中心——Origin 在 Polygon 与 Anubis 的全部 61 个合约，含是否开源/代理/可升级/Owner/多签。
  • 钱包监控·链上体检——任意地址的身份、资产、活动时间线、授权风险。
  • 链上证据库——从 LGNS 创世到 Anubis 上线的关键事件，每条带真实交易哈希。
  • Origin 链上日报——每天自动生成的链上日报（价格/供应/质押/国库/大额成交）。
  • 查推荐人、收益计算器、代币安全自查、大额成交监测、链上数据面板。

服务哪些用户

Origin / LGNS / Anubis 生态的新手、持有者、研究者，以及任何想在做决定前先把链上数据核实清楚的人。

About Web3Origin

In one line: Web3Origin is the on-chain data lookup and research platform for the ORIGIN ecosystem. We turn "what others tell you" into "what you verify on-chain yourself" — check contracts, check wallets, read the daily report, look up evidence, all independently verifiable on a block explorer.

Who We Are

Web3Origin (web3origin.com, also known as "ORIGIN Learn") is an independent on-chain data platform centered on ORIGIN / LGNS / Anubis Chain. It is primarily in Chinese, with an English version (/en/). We do not custody assets and do not connect wallets — we only do lookup, verification and research of public on-chain data.

What Problem We Solve

The biggest problem in Web3 is information asymmetry — ordinary users can usually only go by "what others say." Web3Origin lets you verify on-chain yourself: whether a token can be minted, what a wallet holds and has done, whether an event really happened, and how much is actually in the treasury — all can be looked up and cross-checked with one click, so you don't have to just trust anyone's word (DYOR).

What Data / Tools We Provide

  • Contract Verification Center — all 61 of ORIGIN's contracts on Polygon and Anubis, including whether each is open-source / a proxy / upgradeable / its Owner / multisig.
  • Wallet Monitor · On-chain Check-up — any address's identity, assets, activity timeline, and approval risks.
  • On-chain Evidence Library — key events from LGNS genesis to the Anubis launch, each with a real transaction hash.
  • ORIGIN On-chain Daily — an auto-generated daily on-chain report (price/supply/staking/treasury/large trades).
  • Referrer lookup, yield calculator, token security self-check, large-trade monitoring, and an on-chain data dashboard.

Who We Serve

The newcomers, holders, and researchers of the ORIGIN / LGNS / Anubis ecosystem, plus anyone who wants to verify on-chain data clearly before making a decision.
