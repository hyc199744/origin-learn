Anubis Chain 网络配置（Chain ID / RPC / 浏览器 / Gas）

发布 2026-07-31 · 更新 2026-07-31 · 数据核验 2026-07-31 · 作者 Web3Origin（独立研究，非项目方）
Anubis Chain 的 Chain ID 是 6714，RPC 为 https://rpc.anubispace.org，区块浏览器为 https://browser.anubispace.org，gas 用 DAI 支付，出块约 2 秒。 把这组参数填进钱包的「添加自定义网络」即可接入。

核心要点

  • Anubis Chain 是起源生态自建的公链，添加到钱包（如 MetaMask / OKX）需要下面这组网络参数。
  • Chain ID：6714（十六进制 0x1A3A）。
  • RPC URL：https://rpc.anubispace.org
  • 区块浏览器：https://browser.anubispace.org
  • Gas 代币：DAI（在 Anubis 链上，原生 gas 用 DAI 支付，18 位精度），出块约 2 秒。

如何添加 Anubis Chain 到钱包

  1. 打开钱包 → 设置 → 网络 → 添加自定义网络。
  2. 网络名称：Anubis Chain；新增 RPC URL：https://rpc.anubispace.org；Chain ID：6714；货币符号：DAI；区块浏览器：https://browser.anubispace.org。
  3. 保存并切换到该网络。注意：在 Anubis 链上支付 gas 需要该链上的 DAI，跨链桥入 DAI 后才能操作。
⚠ 添加网络只是把 RPC 填进钱包，不会泄露你的私钥/助记词。任何要求你为「激活网络」输入助记词、私钥或转账的，都是诈骗。

常见问题

Anubis Chain 的 Chain ID 是多少？

6714（十六进制 0x1A3A）。

Anubis Chain 的 RPC 是什么？

https://rpc.anubispace.org 。区块浏览器为 https://browser.anubispace.org 。

Anubis Chain 用什么支付 Gas？

用 DAI 支付。在 Anubis 链上原生 gas 就是 DAI（18 位精度），需先跨链桥入 DAI 才能操作。

Anubis Chain 和 Polygon 有什么区别？

Polygon 是通用公链、gas 用 POL；Anubis 是起源生态自建链、Chain ID 6714、gas 用 DAI、出块约 2 秒。LGNS 在两条链上都有合约。
