LGNS 在哪条链？

发布 2026-07-31 · 更新 2026-07-31 · 数据核验 2026-07-31 · 作者 Web3Origin（独立研究，非项目方）
LGNS 同时在两条链上：Polygon（合约 0xeB51…0F01，主交易在 QuickSwap LGNS/DAI 池）和起源自建的 Anubis Chain（合约 0x4D1D808a…，Chain ID 6714，gas 用 DAI）。 两条链是不同合约地址，操作前请核对链和地址。

核心要点

  • LGNS 同时存在于两条链：Polygon（主）和起源自建的 Anubis Chain。
  • Polygon 上 LGNS 合约：0xeB51…04A0F01，9 位精度，主要交易在 QuickSwap 的 LGNS/DAI 池。
  • Anubis Chain 上 LGNS 合约：0x4D1D808a…28C06B8（Chain ID 6714，gas 用 DAI）。
  • 两条链上的 LGNS 是不同链的不同合约地址，跨链需通过官方桥，别把地址填错链。

链上信息

LGNS · Anubis Chain（ChainID 6714）0x4D1D808a081FdAc440703b3765FC61f8028C06B8
精度9 位（两条链一致）

核实方式

可核实 在 Polygonscan 打开 Polygon 合约、在 browser.anubispace.org 打开 Anubis 合约，均可读 symbol=LGNS、decimals=9。注意 添加/跨链时务必核对链和地址，防止发错链丢币。

常见问题

LGNS 是哪条链的币？

主要在 Polygon，同时在起源自建的 Anubis Chain 上也有合约。两条链地址不同。

LGNS 的 Polygon 合约地址是什么？

0xeB51D9A39AD5EEF215dC0Bf39a8821ff804A0F01，9 位精度。

LGNS 在 Anubis 链的合约是什么？

0x4D1D808a081FdAc440703b3765FC61f8028C06B8（Anubis Chain ID 6714）。

两条链的 LGNS 能互转吗？

需要通过官方跨链桥，直接把一条链的地址用在另一条链会导致资产丢失。
