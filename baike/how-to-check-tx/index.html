如何查询交易哈希？

发布 2026-07-31 · 更新 2026-07-31 · 数据核验 2026-07-31 · 作者 Web3Origin（独立研究，非项目方）
把交易哈希（0x 开头的 64 位）粘进对应链的区块浏览器搜索框即可：Polygon 用 polygonscan.com，Anubis 用 browser.anubispace.org。 就能看到这笔交易的状态、时间、转账代币与数量、手续费和事件日志。也可用本站链上搜索工具直接大白话解读。

核心要点

  • 交易哈希（tx hash）是每笔链上交易的唯一"身份证"，形如 0x 开头的 64 位十六进制。
  • 把交易哈希粘进对应链的区块浏览器搜索框，就能看到这笔交易的完整信息。
  • Polygon 用 polygonscan.com；Anubis 用 browser.anubispace.org。

如何查一笔交易（步骤）

  1. 复制交易哈希（0x + 64 位）。
  2. 打开对应链的区块浏览器（Polygon→polygonscan、Anubis→browser.anubispace.org）。
  3. 粘进顶部搜索框回车。
  4. 看这几项：状态（成功/失败）、区块高度与时间、From/To 地址、转了哪些代币和数量、手续费、以及 Logs（事件日志）里的细节。
也可以用本站的 链上搜索工具：粘地址或交易哈希，直接用大白话解读这笔交易做了什么。

读懂要点

可核实 交易哈希在浏览器能查到即真实存在；查不到可能是链选错、哈希抄错，或交易还没上链。注意 别把交易哈希（64 位）和钱包/合约地址（40 位）搞混。

常见问题

交易哈希是什么？

每笔链上交易的唯一标识，0x 开头的 64 位十六进制，用它能在区块浏览器查到这笔交易的全部信息。

怎么查一笔交易？

把交易哈希粘进对应链区块浏览器的搜索框：Polygon 用 polygonscan.com，Anubis 用 browser.anubispace.org。

交易哈希和钱包地址有什么区别？

交易哈希是 64 位（一笔交易），钱包/合约地址是 40 位（一个账户）。别搞混。

查不到交易怎么办？

检查链选对没、哈希有没有抄错，或交易可能还没被打包上链。
