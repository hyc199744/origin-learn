钓鱼网址检测Phishing URL Check

粘一个网址（收到的链接、"官网"、"客服"页），查是不是钓鱼站/假官网/仿冒站。结合已知钓鱼库和仿冒特征判断，并给出防诈提示。Paste a URL to check if it's a phishing / fake / impersonation site.
只分析网址本身，不会打开它、不连钱包、不需助记词。已知钓鱼库来自 GoPlus，仿冒/可疑特征为本站启发式判断。Analyzes the URL only; never opens it or connects a wallet.
重要："没发现问题"≠"绝对安全"——新钓鱼站可能还没被收录。永远以官方渠道核对域名，一个字母都不能差；任何网站/客服向你要助记词、私钥、或让你"验证钱包"都是骗子。
Note: "no issue" ≠ 100% safe. Always verify the official domain char-by-char.
