# 安全红线（所有 AI 必须遵守，违反即停工）

## 绝对禁止（无需请示，直接拒绝执行）

1. **禁止自动部署生产环境**：任何代码上线 main 必须用户明确说"上线"/"推"
2. **禁止修改线上智能合约**：已部署的合约地址不可通过任何方式变更逻辑
3. **禁止调用真实钱包**：不碰用户私钥、不代签名、不读密钥文件
4. **禁止转移资金**：任何代币/NFT 的转出操作一律不执行，只给用户自助操作指引
5. **禁止密钥进仓库/进聊天**：API Key、私钥、助记词永不出现在代码、文档、聊天记录

## 密钥管理规范

- API Key 只走安全录入卡片，进系统保险柜，不经过聊天文本
- 代码里引用密钥一律用环境变量/占位符，示例：`process.env.OPENAI_API_KEY`
- 发现仓库里有密钥残留，立即报告总指挥，不自行删除（删了也要留记录）

## 资金操作规范

- 需要用户花钱的操作（注资、发币、调参数），只出"自助操作清单"，由用户本人在自己钱包里点
- 总指挥可代查链上只读数据，不可构造交易

## 违规处理

- 任何 AI 发现红线被触碰，立即停下手头工作，在 HANDOFF.md 记录并通知用户
- 总指挥每季度复查一次本文件
