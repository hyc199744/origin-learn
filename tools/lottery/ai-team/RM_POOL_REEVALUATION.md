## 一、修正后的套利模型

攻击者独买 + 控制完整二级链（A买→B拿3%→C拿1%，合计返还 4% 票款）：

```
利润 = 解锁补贴 + 返佣 − 平台费
     = T×s + T×price×4% − T×price×10%
     = T×(s − price×6%)
套利条件：s > price × 6%
```

## 四、设 unlockPerTicket = 0 的可行性：确认可行

- 合约 `setUnlockPerTicket` 无下限检查，设 0 合法
- `_unlockJackpot` 首行：`if (lockedJackpot==0 || unlockPerTicket==0) return;`
- 效果 = 暂停补贴释放；锁定池资金原地冻结；owner 仍可 `withdrawLocked` 取回
- **这是最安全的选项**，且与"暂时禁止 RM 锁定池注资"决策一致（当前余额本就为 0）

## 五、滚存放大的补充分析

当某轮票数 <14 张时，未派奖项滚存（如 5 张票滚存 18%）。
攻击者可多轮滚雪球：每轮独买→拿 50% 一等奖→剩余滚存→下轮奖池更大。
在 s=0.3 下，滚存使套利收益逐轮放大。**设 s=0 后，滚存仅来自真实票款，不再被补贴放大。**

## 六、最终建议

1. **RM 池**：`setUnlockPerTicket(0)`（暂停补贴），维持注资禁令
2. **USDT/DAI/A 池**：`setUnlockPerTicket` 从 0.3 降至 0.15（50% 安全余量）
3. **LGNS 池**：保持 0.3（已有 50% 余量）
4. 以上均由 owner 钱包执行，**只出方案，不代操作**
