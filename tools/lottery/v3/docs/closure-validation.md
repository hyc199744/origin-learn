| 资产与退款 | 钱包余额、网络 Gas、四个游戏的可领资金分开；给出领取入口；未绑定也能访问 |

| 失败与帮助 | 查询失败不当作零/空记录；帮助、资产、返佣互通；问题摘要只复制；开奖过期给出处理入口 |

## 浏览器联调（全部为本地模拟）

本地测试服务仅在 HTML 响应中插入测试 fixture；生产 HTML 不引用 fixture。fixture 替换钱包、RPC、返佣和对战服务，不产生真实签名、下注、授权或转账。

已观察到：

1. 未绑定进入首页出现邀请确认；先选官方候选，再换 `XYZ789`，确认后邀请页显示后来选择的邀请人。
2. 对战页加载不自动登录/授权；显式登录后仍未授权；创建动作先展示额度输入、游戏/代币/代发地址。
3. 输入 `25 LGNS`，模拟回执及权限复查完成后回到大厅；没有自动开桌；再次创建后才进入确认的 `#1001`，仍需主动准备。
4. 资产页显示四个币种各 `0.5` 可领；手机视图领取 LGNS 后该项变成 `0`、领取按钮消失，并出现已确认交易记录。
5. 未绑定且 RPC 报错时资产页仍能打开；余额和历史显示查询失败，不显示虚假零余额或空记录。
6. 英文菜单点击后 HTML 语言立即变成 `en`，资产、退款、邀请、历史与错误状态同步为英文。
7. 资产页使用 390×844、844×390、820×900 三种 iframe 视口验证；实际可用宽度分别 375、829、805，scrollWidth 均与其相等，无横向溢出。
8. 牌桌平板页的钱包按钮原本溢出 36px，导航换行后 805px 可用宽度与 scrollWidth 相等。手机权限弹窗外宽 375px、内容宽与 scrollWidth 均为 373px，地址与英文说明没有横向溢出。

这些结果仅验证前端状态和本地模拟交互，不等于真实服务的完整结算、返佣支付或随机结果可验证性已通过。
